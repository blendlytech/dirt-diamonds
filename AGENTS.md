# Dirt & Diamonds — agent entry point

Read [GEMINI.md](GEMINI.md) before doing anything. It holds the binding project directives for every model, whatever its brand.

Then read, in order:

1. [docs/README.md](docs/README.md): which doc is authoritative.
2. [docs/GAME_VISION.md](docs/GAME_VISION.md): the game, start to finish (v3.0, canonical).
3. [docs/TEAM.md](docs/TEAM.md): current roles. Only start a slice assigned to you, from a brief in `docs/tasks/`, in your own git worktree.
4. [docs/progress.md](docs/progress.md): where the build stands.

Agent rules and skills live in `.agents/rules/` and `.agents/skills/`.
